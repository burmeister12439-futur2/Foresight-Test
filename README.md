# Foresight für Anfänger, auch für Fortgeschrittene

Ein interaktiver Selbstversuch in drei Teilen: Was macht gute Foresight aus, wo stehen Sie selbst? Mit Typ-Test, zwei Schaubildern und einer aufklappbaren Fortgeschrittenen-Ebene.

Ein Werkzeug aus dem von D2030 initiierten Projekt „foresight_D".

## Öffentliche Version

Die Seite läuft über GitHub Pages: https://burmeister12439-futur2.github.io/Foresight-Test/

Die Datei `index.html` ist vollständig eigenständig (HTML, CSS und JavaScript in einer Datei, keine externen Abhängigkeiten).
